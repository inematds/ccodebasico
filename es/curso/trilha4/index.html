🟡 Qué es

Una Skill es un conjunto reutilizable de instrucciones que enseña a Claude a ejecutar un flujo de trabajo específico de forma predecible. Es un archivo SKILL.md con un frontmatter (name + description) que vive en .claude/skills/.

💡 Por qué aprender

El secreto de las Skills: ellas solo se cargan cuando son necesarios. A diferencia de CLAUDE.md (siempre en la memoria), la Skill ahorra contexto y aparece solo en el momento adecuado: Claude lee la description y decide invocarlo.

🔑 CLAUDE.md vs Skill

CLAUDE.mdSkill
Siempre cargadoSolo se carga cuando se invoca
Reglas globales del proyectoFlujos de tareas específicos
Ej.: "Usa TypeScript"Ej.: "Generar resumen de PR"

Regla práctica: si Claude debe siempre saber → CLAUDE.md. Si es para una tarea específica → Skill.

🟡 Qué es

No necesitas escribir la Skill desde cero: la skill skill-creator te entrevista y genera el SKILL.md. Lo esencial es la description bien escrita — es la que hace que Claude sepa cuando usar.

💡 Por qué aprender

Una Skill bien hecha elimina la repetición: escribes el «cómo hacerlo» una vez y se reutiliza para siempre. La guía oficial de Anthropic organiza esto en 6 capítulos, desde los fundamentos hasta la distribución.

🔑 Estructura mínima de una Skill

---
name: pr-review
description: Use quando pedir revisão de PR, diff ou código alterado.
---
Ao revisar um PR:
1. Leia o diff completo
2. Aponte riscos de segurança
3. Verifique cobertura de testes
4. Classifique os achados por severidade
1. Fundamentos
2. Planificación y diseño
3. Pruebas e iteración
4. Distribución
5. Patrones y problemas
6. Recursos y referencias

🟡 Qué es

Los plugins agrupan skills, comandos, agentes y hooks en un paquete instalable. Agrega un marketplace (un repositorio de GitHub) e instalas plugins desde ahí con /plugin.

💡 Por qué aprender

Los plugins son la forma más rápida de potenciar Claude Code con el trabajo de la comunidad. P. ej.: Claude Mem da memoria entre sesiones; el Vision plugin le da ojos para leer imágenes/pantallas.

🔑 Instalar un plugin

# 1. adicione o marketplace (repo)
/plugin marketplace add thedotmack/claude-mem
# 2. instale o plugin
/plugin install claude-mem

⚠️ Atención: para Claude Mem, no uses npm install — esto instala solo la lib y los los hooks no se registran. Usa exactamente los dos comandos /plugin arriba.

🟡 Qué es

Además del CLAUDE.md, Claude Code tiene memoria persistente en .claude/projects/<projeto>/memory/, gestionada por /memory. O Memory 2.0 / Auto Dream consolida estas memorias automáticamente.

💡 Por qué aprender

Memoria entre sesiones = dejas de tener que volver a explicar el proyecto cada vez. El agente recuerda las decisiones, correcciones y convenciones de ayer. Es lo que convierte a Claude en un colega que conoce tu código.

🔑 Cómo funciona el "dream"

1

Ejecuta en segundo plano, por sí solo — no es un comando que se ejecuta

2

Se activa cuando: 24h+ desde el último dream y 5+ sesiones acumuladas

3

Consolida por proyecto — los que más usas se consolidan primero

/memory nativo

Memoria del proyecto, controlada por Anthropic (despliegue gradual)

Claude Mem (plugin)

Captura ediciones/decisiones → SQLite con búsqueda vectorial, las inyecta al inicio

🟡 Qué es

El CLAUDE.md tiene jerarquía: tus reglas (globales), las del proyecto y las locales se combinan. Un buen CLAUDE.md es breve, específico y está organizado en viñetas — no es una novela. La idea de un "prompt universal" es tener una estructura reutilizable entre proyectos.

💡 Por qué aprender

CLAUDE.md inflado consume contexto en cada sesión. Lo avanzado es saber qué no poner (lo que está en el código) y lo que vale oro (comandos, convenciones, «nunca hagas X»).

🟡 Qué es

Las skills de diseño enseñan a Claude a crear una UI realmente atractiva. La frontend-design (Anthropic) ya viene en el kit; la Impeccable es un fork enriquecido — con 7 referencias de dominio siempre cargadas y un detector de «AI slop».

💡 Por qué aprender

La diferencia entre una página "de IA genérica" y una página premium está en estas skills. Impeccable ofrece un vocabulario de iteración (23 comandos verbales) para refinar, no solo "construye una página".

🔑 Impeccable en resumen

7 refs de dominio

tipografía, color (OKLCH), espacio, motion, interacción, diseño responsivo, UX writing

23 comandos verbales

/polish /audit /critique /harden /animate /layout /distill…

Detector de antipatrones

npx impeccable detect src/ — detecta «AI slop» sin API key

/teach + /extract

Genera PRODUCT.md + DESIGN.md como un sistema de diseño vivo

Cuándo usar frontend-design de Anthropic: UI rápida de "one-shot", sin instalar nada adicional. Impeccable: cuando vas a iterar y quieres un sistema de diseño de verdad.
