🟢 Qué es

O MCP (Model Context Protocol) es el «estándar USB» que conecta Claude Code con herramientas externas: bases de datos, navegadores, APIs, documentación. Cada servidor MCP expone herramientas que Claude puede usar, como leer datos de Supabase, extraer datos de un sitio o controlar el navegador.

💡 Por qué aprender

Sin MCP, Claude solo ve tus archivos. Con MCP, actúa en el mundo: consulta tu base de datos real, abre páginas y obtiene datos en vivo. Es lo que transforma al agente de «editor de código» en «operador de sistemas».

🔑 Cómo agregarlo y dónde vive

claude mcp add firecrawl "npx -y firecrawl-mcp"   # adiciona um server
claude mcp list                                    # lista os configurados
/mcp                                               # painel dos servers na sessão
AlcanceDónde conviene
localSolo tú, solo este proyecto
projectVe a .mcp.json (commit, todo el equipo)
userTú, en todos los proyectos

🟢 Qué es

Un puñado de servidores MCP resuelve la mayoría de los casos: Supabase (banco), Firecrawl (raspar la web), Playwright (controlar el navegador) y NotebookLM (base de conocimiento). Todos entran con un claude mcp add.

💡 Por qué aprender

Con Supabase MCP, Claude lee y migra tu base de datos real sin que tengas que copiar el esquema; con Firecrawl obtiene contenido de cualquier sitio; con Playwright prueba la UI haciendo clic de verdad. Es una productividad que no puedes fingir con un prompt.

claude mcp add playwright "npx -y @playwright/mcp@latest"

Consejo: después de agregar, ejecuta /mcp para confirmar que el server se conectó (✓ verde) antes de pedir la tarea.

🟢 Qué es

Claude Code busca la clave en ANTHROPIC_API_KEY y la URL en ANTHROPIC_BASE_URL. Al cambiar esta URL por un enrutador (CCR — claude-code-router) o un servidor local (Ollama), puedes ejecutarlo con otros modelos, incluso gratis.

💡 Por qué aprender

Para estudiar, probar o hacer tareas sencillas, no necesitas gastar tokens caros. CCR dirige las solicitudes a proveedores gratuitos o económicos; Ollama ejecuta modelos en tu máquina, sin conexión. Mantiene el flujo de Claude Code y solo cambia el «motor».

🔑 Las dos rutas

CCR — claude-code-router
npm install -g @musistudio/claude-code-router
ccr code        # abre o Claude Code roteado p/ outro provedor
# github.com/musistudio/claude-code-router
Ollama (modelo local)
ollama pull qwen2.5-coder
export ANTHROPIC_BASE_URL="http://localhost:11434"
claude   # usa o modelo local, offline

💡 Cuándo usar: los modelos locales/gratuitos son excelentes para estudiar y para tareas livianas; para el trabajo serio, Sonnet/Opus oficiales ofrecen mucho más. Usa cada uno para lo que corresponde.

🟢 Qué es

Las Routines son automatizaciones que se ejecutan en la nube — sin dejar la PC encendida. Tú defines un prompt, un repositorio de GitHub, un modelo y una frecuencia; la activación puede ser por programación, API o evento de GitHub. En cambio, el /loop y las scheduled tasks se ejecutan localmente.

💡 Por qué aprender

Es Claude convertido en un miembro del equipo que trabaja solo: revisa PRs, actualiza dependencias, genera informes — en un horario programado, sin que tú intervengas. La trampa: el entorno en la nube es sin estado e no ve tu .env local; los secretos van como variables de entorno de la nube.

🔑 Local × Nube

TipoDónde se ejecutaDetalle
RoutinesNube (sin estado)PC apagada · frecuencia mínima ~1h · necesita un repo de GitHub
Scheduled tasksLocal (escritorio)Accede a archivos locales
/loopLocal (sesión)Intervalos cortos · no sobrevive a un reinicio

Límites por plan: Pro ~5/día · Max ~15/día · Team/Enterprise ~25/día. Cada ejecución en la nube ≈ 4 vCPU / 16 GB RAM.

⚠️ Trampa: rutina remota no tiene cookies ni sesión del navegador local. La automatización que depende de un inicio de sesión guardado falla: usa una API o autenticación propia, y haz varias pruebas antes de pasar a «producción».

🟢 Qué es

Herramientas que muestran, en tiempo real, cuánto estás gastando e qué están haciendo tus agentes: consumo de tokens, costo, sesiones abiertas y múltiples terminales. La comunidad creó varios — Token-Dashboard, iccmonit, SMA (Surveil My Agents), Agent View.

💡 Por qué aprender

Quien ejecuta varios agentes en paralelo (trilha 6) pierde la noción del gasto y del estado. Un monitor evita sorpresas en la factura y muestra qué terminal se bloqueó o terminó. /cost resuelve lo básico; los dashboards dan una visión general.

🟢 Qué es

Anthropic lanza nuevas versiones de Sonnet e Opus con frecuencia — Claude Code apunta a las más recientes. Para búsqueda semántica (RAG, "segundo cerebro"), entran los embeddings, donde modelos como Gemini Embedding son populares por ser baratos/gratuitos.

💡 Por qué aprender

Saber la diferencia entre modelo de chat (genera código/texto) y modelo de embeddings (transformar texto en vectores para búsquedas) evita confusiones. El primero lo cambias con /model; el segundo alimenta tu RAG (ruta 6).

🔑 Chat × Embedding

TipoHaceEjemplos

/model         # ver e trocar o modelo de chat ativo
/model sonnet  # último Sonnet (dia-a-dia)
/model opus    # último Opus (tarefas difíceis)
