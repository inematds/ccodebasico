Conteúdo detalhado

🔴 O que é

Um subagente é uma instância do Claude com sua própria janela de contexto, disparada pelo agente principal para uma tarefa específica. Vários rodam em paralelo, cada um devolve só a conclusão — sem inundar o contexto principal. Você cria e configura subagentes com /agents.

💡 Por que aprender

Auditoria, pesquisa ampla e refactor dividido em paralelo cortam o tempo total. E como cada subagente tem contexto próprio, eles vasculham muitos arquivos sem gastar o seu — você fica com a conclusão, não com o despejo de tudo que leram.

🔑 Fórmula do prompt

Use subagentes em paralelo para [objetivo].
Divida:
1. Subagente A: [papel específico]
2. Subagente B: [papel específico]
3. Subagente C: [papel específico]
Regras: trabalho independente, não editem ainda,
        consolidem os achados no final.

O Claude não cria subagentes sozinho na maioria das tarefas — você pede. Padrões como o DeepClaudex empacotam essa orquestração (fan-out → verificação → síntese) num fluxo repetível.

🔴 O que é

Um passo além dos subagentes: uma equipe de agentes com papéis fixos que se comunicam. O backend avisa o frontend quando termina; o frontend manda pro QA; o QA devolve bugs pra correção. Há também o orquestrador analítico (AOA) — um agente que coordena os demais.

💡 Por que aprender

Para projetos com etapas dependentes (API → UI → testes), o time entrega um fluxo realista de software, com handoff e revisão — não só pedaços soltos. É o pulo do "agente que ajuda" pro "equipe que produz".

🔑 Prompt de um time full-stack

Crie um time de 3 teammates usando Sonnet:
• Backend dev  → REST API, modelo de dados, endpoints
• Frontend dev → espera o backend, então cria o React que consome a API
• QA agent     → testa o app pronto, acha bugs, gera relatório pass/fail

Handoff: backend → avisa frontend → envia ao QA.
Entregáveis: app rodando + relatório de testes + doc de como rodar.

🔴 O que é

O Cowork é o modo do Claude focado em executar tarefas e automações do dia (não programar): organizar arquivos, analisar e-mails, gerar relatórios, conectar apps. Pense nele como um colega digital a quem você delega trabalho — e paga em tokens, não em salário.

💡 Por que aprender

Saber qual ferramenta usar evita frustração: nem tudo é "código". O dispatch do Cowork dispara tarefas que rodam em segundo plano, e os projetos guardam contexto e instruções globais reaproveitáveis.

🔑 Qual usar quando

FerramentaUse para
ChatRespostas rápidas, ideias, brainstorming
CoworkExecutar tarefas e automações (arquivos, e-mail, relatórios)
CodeProgramar, scripts, APIs, automações avançadas
Anti-GravityIDE completa pra desenvolver apps com IA

Mentalidade: trate a IA como funcionário digital. Defina global instructions uma vez, crie projetos por área e use dispatch pra rodar tarefas sem ficar olhando.

🔴 O que é

Apontar o Claude Code para o seu vault do Obsidian (suas notas em Markdown) e usá-lo como um segundo cérebro: ele lê, conecta e escreve nas suas notas. Um CLAUDE.md base define a estrutura, e a pasta variants/ guarda versões do sistema para perfis diferentes (freelancer, estudante, dev…).

💡 Por que aprender

Suas notas viram contexto vivo: o Claude responde com base no que você sabe, não só no treino dele. É o approach "RAG sobre o seu conhecimento" que o Karpathy popularizou — memória externa pesquisável em vez de despejar tudo no prompt.

🔑 Estrutura típica

vault/
├── CLAUDE.md          # regras, contexto, como organizar as notas
├── projetos/          # notas por projeto
├── decisoes/          # log de decisões
└── variants/          # versões do sistema p/ cada perfil
    ├── freelancer/
    ├── developer/
    └── student/

Combine com a trilha 5 (MCP): um servidor de embeddings/busca deixa a recuperação das notas mais precisa em vaults grandes.

🔴 O que é

Os mesmos blocos (subagentes + skills + memória) montados como assistentes verticais: um assistente pessoal (PA AI), um assistente local que roda na sua máquina (ClaudeClaw), um executivo, um jurídico e até uma equipe de 5 agentes de contabilidade.

💡 Por que aprender

Mostra que "agente" não é só pra código. Trocando o CLAUDE.md, as skills e as ferramentas (MCP), o mesmo Claude Code vira o motor de um produto de nicho — o pulo do estudo pra aplicação real.

🔑 Exemplos da comunidade

🧑‍💼 PA AI / Executivo

Agenda, e-mails, follow-ups, briefings

🐾 ClaudeClaw (local)

Assistente pessoal rodando na sua máquina

⚖️ Jurídico

Analisa contratos e documentos com regras próprias

📊 5 Agentes de Contabilidade

Time dividindo lançamentos, conciliação e relatórios

🔴 O que é

Fechar o ciclo: agentes que rodam sozinhos. Um AutoResearch loop pesquisa um tema, verifica e sintetiza repetidamente até cobrir tudo; o Trigger.dev agenda e dispara agentes por eventos/cron; "agentic" é a mentalidade de encadear esses passos em automação contínua.

💡 Por que aprender

É o que transforma o Claude num membro da equipe que trabalha enquanto você dorme: revisões agendadas, pesquisa recorrente, relatórios automáticos. Junte com Routines (trilha 5) pra disparar por horário.

🔑 Padrão loop-até-cobrir

1

Disparar buscas em paralelo (vários ângulos do tema)

2

Verificar cada achado de forma adversarial (refutar)

3

Repetir até 2 rodadas sem nada novo (loop-until-dry)

4

Sintetizar relatório final e agendar a próxima rodada (Trigger.dev)
