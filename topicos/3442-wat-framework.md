# 🎯 Projeto: “Espanhol Vivo”

Curso comunitário de espanhol para crianças (baixo custo e alto impacto)

---

## 1️⃣ WORKFLOW (O que fazer)

### Objetivo

Ensinar espanhol para crianças de forma divertida, prática e acessível, mesmo sem recursos financeiros.

### Público-alvo

* Crianças de 6 a 12 anos
* Comunidades com pouco acesso a cursos pagos

### Resultado esperado

* Crianças conseguindo:

  * Se apresentar
  * Fazer perguntas simples
  * Entender músicas e histórias básicas
  * Ter confiança para falar

---

## 2️⃣ AGENT (Como organizar)

Você como coordenador vai:

* Criar aulas simples e repetíveis
* Usar materiais gratuitos
* Aplicar metodologia baseada em:

  * Música 🎵
  * Teatro 🎭
  * Jogos 🧩
  * Movimento 🏃

Nada de aula tradicional parada e chata.

---

## 3️⃣ TOOLS (Como executar sem dinheiro)

Aqui está a parte inovadora 👇

### 🔹 Tool 1: Método “Missão Semanal”

Cada semana é uma missão:

Exemplo:

* Missão 1: “Sobrevivência”

  * Hola, ¿cómo te llamas?
  * Me llamo…
  * ¿Cuántos años tienes?

* Missão 2: “Supermercado”

  * Quiero…
  * Cuánto cuesta
  * Números

Gamificação simples:

* Cada missão concluída = medalha de papel
* 5 missões = certificado

Custo: zero.

---

### 🔹 Tool 2: Espanhol com Movimento

Crianças aprendem melhor com corpo.

Exemplo:

* “Salta cuando escuches rojo”
* “Corre si escuchas azul”
* “Toca la mesa cuando diga perro”

Aprendem sem perceber.

* Montar mini peça em espanhol

* Gravar com celular

Isso:

* Motiva

* Atrai voluntários

**INEMA** · 2026-02-28

O **WAT (Workflows, Agents, Tools)** é uma arquitetura criada para tornar sistemas com IA **mais confiáveis, organizados e escaláveis**.

Ele separa:

* 🧠 **Raciocínio (IA)** → feito pelo *Agent*
* ⚙️ **Execução (código determinístico)** → feita pelos *Tools*
* 📋 **Instruções (processos)** → definidas nos *Workflows*

Essa separação evita que a IA tente fazer tudo sozinha (o que reduz drasticamente a precisão em tarefas com múltiplos passos).

---

## 🏗 Como funciona

### 1️⃣ Workflows (O que fazer)

São SOPs em Markdown que explicam:

* Objetivo
* Inputs necessários
* Ferramentas a usar
* Saídas esperadas
* Tratamento de erros

É como um manual operacional.

---

### 2️⃣ Agent (Quem decide)

O agente:

* Lê o workflow
* Decide quais tools usar
* Executa na ordem correta
* Lida com erros
* Faz perguntas quando necessário
* Atualiza o workflow quando aprende algo novo

Ele **coordena**, não executa tudo manualmente.

---

### 3️⃣ Tools (Quem executa)

São scripts Python que fazem:

* Chamadas de API
* Transformações de dados
* Scraping
* Operações em arquivos
* Integrações com serviços

São previsíveis, testáveis e rápidos.

---

## 🔁 Ciclo de melhoria contínua

Quando algo falha:

1. Identifica o erro
2. Corrige a tool
3. Testa
4. Atualiza o workflow
5. Sistema fica mais robusto

O sistema aprende estruturalmente, não apenas na conversa.

---

## 🚀 Como usar na prática

1. Defina ou escolha um **workflow**
2. O agente lê o workflow
3. O agente usa as **tools existentes**
4. Se não existir tool adequada, cria uma
5. Corrige e melhora continuamente

**INEMA** · 2026-02-28

O **WAT Framework** é um modelo para organizar como a IA trabalha com código.

De forma simples:

> Ele separa **pensar**, **executar** e **seguir processo**.

---

## O que é, direto ao ponto:

É um sistema dividido em 3 partes:

1. **Workflows** → dizem *o que fazer* (passo a passo escrito em Markdown)
2. **Agent** → decide *como fazer* (a IA coordena)
3. **Tools** → fazem *o trabalho pesado* (scripts que executam de forma segura e previsível)

---

## Por que ele existe?

Porque quando a IA tenta:

* Pensar
* Executar código
* Tomar decisões
* Lidar com APIs
* Tratar erros

Tudo ao mesmo tempo… a chance de erro aumenta muito.

O WAT resolve isso separando responsabilidades.

---

## Em uma frase:

> WAT é uma arquitetura que faz a IA pensar e organizar, enquanto scripts fazem a execução real.
