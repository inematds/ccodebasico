**INEMA** · 2026-02-16

Guia oficial da Anthropic sobre **Skills no Claude Code**, um recurso que permite ensinar o Claude a executar seus fluxos de trabalho específicos de forma estruturada e previsível.

Uma **skill** funciona como um manual de onboarding para o Claude. Ela define **o que fazer, quando fazer e como fazer**. É composta principalmente por um arquivo `skill.md`, que inclui:

* **YAML front matter** (nome, descrição e gatilhos de uso)
* Instruções detalhadas
* Scripts e arquivos auxiliares

Existem **3 níveis de execução**:

1. YAML (sempre carregado)
2. Instruções completas
3. Scripts e dependências (carregados só se necessário)

**MCPs são as ferramentas** (conectam Claude a serviços externos), enquanto **skills são as receitas** (ensinam como usar essas ferramentas corretamente).

Para criar uma boa skill:

* Seja específico no que ela faz
* Defina claramente quando deve ser usada
* Inclua palavras-chave (triggers)
* Estruture instruções em passos claros

O guia apresenta **5 padrões de design**:

1. Fluxo sequencial
2. Coordenação entre múltiplos MCPs
3. Refinamento iterativo
4. Fluxo condicional (ramificações)
5. Inteligência empresarial com regras internas

Também ensina a testar skills:

* Teste de gatilho
* Teste funcional
* Teste de valor (ver se realmente compensa usar)

Conclusão:
Skills transformam o Claude em um executor consistente dos seus processos. Quando bem feitas, tornam os fluxos mais previsíveis, eficientes e reutilizáveis — mas devem ser específicas, bem testadas e evoluir junto com seu workflow.
