# 1. Quando usar cada ferramenta (Chat vs Cowork vs Code vs Anti-Gravity)

**Chat**
Use quando quiser **respostas ou ideias rápidas**.

Exemplos:

* escrever texto
* tirar dúvidas
* brainstorming

**Cowork**
Use quando quiser **executar tarefas e automações**.

Exemplos:

* organizar arquivos
* analisar emails
* criar relatórios
* conectar apps

**Code**
Use quando quiser **programar ou criar scripts**.

Exemplo:

* criar software
* APIs
* automações avançadas

**Anti-Gravity (IDE)**
Ambiente completo para **desenvolver aplicações com IA**.

Exemplo:

* criar SaaS
* dashboards
* ferramentas internas

# 8. Plugins

Plugins são **processos completos**.

Diferença:

Skill
= uma tarefa.

Plugin
= um sistema com várias etapas.

Exemplo de plugin:

Workflow de conteúdo:

1. pegar vídeo do YouTube
2. pegar transcript
3. criar post LinkedIn
4. criar post Twitter
5. salvar no Notion

Tudo com **um comando**.

# Resumo – Claude Cowork FULL COURSE (Automate Everything)

## 1. Visão geral do Claude Ecosystem

O Claude possui **três modos principais**:

* **Claude Chat** → para perguntas e conversas simples.
* **Claude Co-work** → para automações, tarefas e workflows conectados às suas ferramentas.
* **Claude Code** → para desenvolver software ou scripts.
* **Google “Anti-gravity” (IDE)** → ambiente para programar usando Claude Code.

📌 Ideia central:
**Chat = perguntas**
**Cowork = automação de tarefas**
**Code = desenvolvimento**

---

# 2. Planos, custos e uso de tokens

Existem três planos:

* Free
* Pro (~$20/mês)
* Max (~$100–200)

Conceito importante:

👉 **IA deve ser vista como um funcionário digital**, não como uma assinatura de software.

### Dicas para economizar tokens

* Use **novas conversas para tarefas diferentes**
* Limite o **contexto carregado**
* Use modelos mais leves quando possível
* Reserve o modelo mais poderoso para tarefas importantes.

---

# 3. Configuração inicial do Claude Cowork

Configurações importantes:

* Definir **preferências de comunicação**
* Ajustar **notificações e privacidade**
* Ver **uso de tokens**
* Importar **memória de outras IAs (ex: ChatGPT)**

Isso permite que o Claude entenda melhor você e seu negócio.

# 4. Criar contexto do seu negócio (Business Brain)

Criar um arquivo com informações como:

* o que seu negócio faz

Esse arquivo ajuda o Claude a dar respostas **mais estratégicas e personalizadas**.
