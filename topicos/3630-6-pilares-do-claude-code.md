# 💙 5️⃣ Claude AI Skills (`claude_ai_skills.md`)

Esse é **um dos mais importantes**.

Ele explica **como criar Skills para Claude**.

### O que são Skills

Skills são **prompts reutilizáveis salvos como arquivos**.

Exemplo:

```.claude/commands/
   code-review.md
   lead-research.md
   screenshot-to-website.md```

Depois você chama:

```/code-review```

ou

```/lead-research```

### Benefícios

* reutilização
* economia de tokens
* automação
* padronização

📌 Basicamente:

> **SOPs (procedimentos operacionais) para IA**

# 🌍 6️⃣ Connecting Claude (`connecting_claude.md`)

Esse arquivo explica **como conectar Claude a ferramentas externas**.

Usando:

```MCP (Model Context Protocol)```

### MCP é como:

```USB ports para IA```

Ele conecta Claude a:

* GitHub
* Banco de dados
* Navegador
* Google Sheets
* Filesystem

### Exemplo

```claude mcp add github
claude mcp add postgres
claude mcp add browser```

📌 Resultado:

Claude pode:

* abrir PR
* consultar banco
* navegar sites
* ler arquivos
