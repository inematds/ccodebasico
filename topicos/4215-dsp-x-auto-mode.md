**PARE de usar a opção de ignorar permissões, use este novo recurso!

**Claude Code acaba de lançar o modo automático, uma nova configuração de permissões que fica entre "perguntar antes de cada edição" e "ignorar permissões de forma perigosa".

Em vez de interromper seu fluxo de trabalho a cada poucos segundos ou dar carta branca para o Claude fazer o que quiser, o modo automático usa um classificador para verificar o risco de cada ação antes de executá-la. 

Ações seguras são executadas automaticamente, enquanto as arriscadas são sinalizadas. Neste vídeo, explico como funciona, testo com alguns exemplos reais e mostro como ativá-lo.
