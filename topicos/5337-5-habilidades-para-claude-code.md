## Top 5 Claude Code Skills

O vídeo apresenta cinco ferramentas ou habilidades que ajudam a usar Claude Code de forma mais eficiente, reduzindo custos, economizando tokens, melhorando pesquisas e acelerando a criação de projetos.

### 1) Graphify

Transforma uma base de código em um grafo de conhecimento.
A ideia é mapear arquivos, conexões, importações e módulos importantes para que o Claude encontre rapidamente as partes relevantes do projeto, sem precisar analisar tudo do zero a cada nova conversa.

É mais útil em projetos grandes, com centenas de arquivos, porque ajuda a economizar muitos tokens e facilita perguntas sobre sistemas complexos.

### 2) Firecrawl

Serve para extrair dados limpos de sites bagunçados.
Em vez de enviar HTML cheio de anúncios, cookies, scripts e elementos desnecessários para a IA, o Firecrawl organiza o conteúdo em um formato mais fácil para agentes de IA processarem.

O exemplo principal é usar a ferramenta para gerar listas de leads, coletando informações como nome da empresa, site, e-mail e detalhes úteis.

### 3) Integração com NotebookLM

Permite usar o NotebookLM de forma programática dentro do Claude Code.
A proposta é criar notebooks personalizados com várias fontes, como vídeos, PDFs e documentos, para depois consultar essas informações de forma organizada.

Isso funciona como uma equipe pessoal de pesquisa, permitindo gerar insights, resumos, estratégias e respostas com base em centenas de fontes sem gastar tantos tokens diretamente no Claude.

### 4) Awesome Design / Biblioteca de identidades visuais

É uma biblioteca com dezenas de estilos de design inspirados em marcas conhecidas.
Ela ajuda a criar sites, páginas e interfaces com visual mais profissional, usando referências de marcas como Apple, Lamborghini, Claude e outras.

A principal vantagem é não começar o design do zero. Você escolhe uma identidade visual, aplica ao projeto e ajusta com prompts até chegar em um resultado bom.

### 5) Claude Code Router

Permite usar a interface do Claude Code, mas roteando tarefas para modelos mais baratos quando não for necessário usar um modelo caro e poderoso.
A lógica é simples: tarefas difíceis usam modelos melhores; tarefas simples podem ser feitas por modelos menores e mais baratos.

Isso pode reduzir bastante o custo com tokens, mas pode trazer algumas limitações, como mais latência, diferenças na qualidade das chamadas de ferramentas e possíveis incompatibilidades com alguns modelos.

## Ideia central

Essas cinco ferramentas ajudam a criar um fluxo de trabalho mais eficiente com IA: entender melhor grandes projetos de código, extrair dados da web, fazer pesquisas profundas, criar designs melhores e economizar dinheiro usando modelos mais baratos quando possível.
